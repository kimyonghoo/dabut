# 지출수단 로고 폴더

이 폴더에 공식 로고 이미지를 직접 넣어 주세요. 아래 파일명을 사용합니다.

| 파일명 | 대상 (이름에 포함된 글자) |
| --- | --- |
| `samsung.png` | 삼성 / Samsung |
| `kb.png` | 국민 / KB |
| `bc.png` | BC / 비씨 |
| `clt.png` | CLT / 복지 |
| `seoulpay.png` | 서울페이 |

- png를 권장하며 svg(`samsung.svg` 등)도 인식합니다. png를 먼저 찾고, 없으면 svg를 찾습니다.
- 정사각형에 가까운 이미지, 투명 또는 흰색 배경, 128x128 이상을 권장합니다.
- 파일을 넣으면 해당 이름이 들어간 지출수단이 표시되는 모든 곳에 자동으로 나타납니다.
- 파일이 없는 동안에는 중립적인 색상의 카드 아이콘 배지가 대신 표시됩니다.
